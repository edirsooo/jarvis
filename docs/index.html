Um assistente que acorda pelo nome

O Whisper transcreve a sua fala no próprio computador e a resposta vem em uma frase, na voz do Edge. Depois de responder, ele segue ouvindo por alguns segundos.

  • “Claude, …”vai para o Claude Code
  • “Codex, …”vai para o Codex
  • “Para tudo”interrompe as missões
  • Espaçoliga e desliga o microfone

O Jarvis se atualiza pelo GitHub com um clique

A cada 6 horas o Jarvis confere se saiu versão nova. Aparece o botão Atualizar com a lista de novidades; ele baixa, reinicia sozinho e, se estava calado, volta calado.

Vale para a cópia clonada pelo git. Com missão rodando, ele espera terminar.

Instale o Jarvis pelo Claude Code

Funciona no Windows (10 e 11), macOS (12+) e Linux. Precisa de Python 3.10 ou mais novo e do Claude Code com a sua conta.

No Claude Code ou no Codex, cole:

Instale o Jarvis deste repositório: https://github.com/edirsooo/jarvis
Clone numa pasta chamada Jarvis, leia o INSTALAR.md e siga o passo a passo de instalação. Meu nome é <seu nome>.

Ou no terminal (no macOS e no Linux, use python3):

git clone https://github.com/edirsooo/jarvis.git Jarvis
cd Jarvis
python instalar.py
Baixar o Jarvis Ver no GitHub
